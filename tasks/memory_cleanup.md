# Memory Cleanup

Clean up and organize memory storage.

## Task
Archive old memories and clean up outdated information to maintain efficient memory usage.

## Steps
1. Identify memories older than threshold (e.g., 30 days)
2. Archive important memories to long-term storage
3. Remove outdated or irrelevant entries
4. Consolidate related memories where appropriate

## Output Format
Summary of cleanup actions:
- Archived Items (count and categories)
- Removed Items (count and reasons)
- Storage Stats (before/after)
- Recommendations for future cleanup
