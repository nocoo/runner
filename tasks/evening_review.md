# Evening Review

Daily evening review and reflection.

## Task
Review the day's activities, accomplishments, and learnings.

## Steps
1. List tasks completed today
2. Note any blockers or issues encountered
3. Identify lessons learned
4. Set priorities for tomorrow

## Output Format
Structured daily review in markdown:
- Completed Tasks
- Challenges & Blockers
- Lessons Learned
- Tomorrow's Priorities
