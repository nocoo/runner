# Weekly Synthesis

Weekly summary and planning session.

## Task
Synthesize the week's work and create a plan for next week.

## Steps
1. Review all completed work from the week
2. Assess progress on monthly/quarterly goals
3. Identify patterns or recurring issues
4. Set priorities and goals for next week

## Output Format
Weekly report in markdown:
- Week Summary
- Goal Progress
- Key Accomplishments
- Challenges & Learnings
- Next Week Priorities
